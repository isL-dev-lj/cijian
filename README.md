# 词间 Cijian

词间是一款 Windows 英语拼写练习工具。写代码、读文章或等任务跑完时，可以按快捷键叫出一个半透明浮窗，练几个词，再按 `Esc` 收起来。练习进度会自动保存，下次从原处继续。

[下载最新版](https://github.com/isL-dev-lj/cijian/releases/latest) · [快速上手](#快速上手) · [从源码构建](#从源码构建)

## 快速上手

1. 在 [最新 Release](https://github.com/isL-dev-lj/cijian/releases/latest) 的发布说明里下载 Windows ZIP。1.0.5 的下载链接是 `Cijian-1.0.5.zip`。
2. 解压到普通文件夹，双击 `Cijian.exe`。程序会先打开管理窗口。
3. 选择词库和练习模式，点击「打开练习」。也可以用管理窗口显示的全局快捷键直接呼出浮窗。

| 操作 | 用法 |
| --- | --- |
| 打开或收起浮窗 | 默认 `Ctrl+Shift+O`。被占用时尝试 `Ctrl+Shift+F10`。 |
| 收起浮窗 | 按 `Esc`，或点击浮窗右上角的 ×。 |
| 移动浮窗 | 按住拼写行、词义或空白处拖动。本次运行中，再次呼出会沿用拖动后的位置。 |
| 播放发音 | 点击单词、句子或填空所在的拼写行。 |
| 打开管理窗口 | 双击系统托盘的词间图标，或在右键菜单选择「管理练习」。 |
| 完全退出 | 在托盘右键菜单选择「退出」。 |

## 练习内容

- **六级词库**包含常见单词和词组，练习时显示中文释义。
- **六级句子库**附中文译文。较长的句子会换行，拼错时保留前面拼对的词。
- **考研大纲词频**按词表顺序推进，每组 50 项。点击当前词旁的星星可以收藏，下一组优先安排最多 10 个已遇到的收藏词。具体词库内容取决于所用构建。

| 模式 | 适合怎么练 |
| --- | --- |
| 跟打 | 看完整拼写输入，熟悉新词或句子。 |
| 挖空 | 补全遮住的部分字母，卡住时按 `Tab` 提示下一字符。 |
| 记忆 | 根据释义回忆拼写，卡住时也可以按 `Tab`。 |
| 刷词 | 连续跟打，练习进度与其他模式分开保存。 |

拼对会短暂确认并自动推进。拼错会标红当前错误，然后回到需要重打的单词。自动朗读与练习提示音可以在管理窗口分别开关。

### 提示回练

在挖空或记忆模式中，只要这一题用过 `Tab`，完成后就会加入回练队列。完成 **3 道新题**后，该词或句子会再次出现，浮窗底部会显示「提示回练」。回练时独立拼对就会移出队列，再用提示则会等 3 道新题后回来。回练单独排队，主词库进度会接着原来的顺序往下走。

## 进度、发音与升级

- 词库位置、收藏、提示回练队列和设置保存在 `%LOCALAPPDATA%\MoyuPractice\progress.txt`。
- 英语单词和短语优先使用与 Reading Desk 同源的有道在线发音。在线播放会向它请求当前英文词条。网络不可用时回退到 Windows 语音，句子使用 Windows 语音。
- 从管理窗口或托盘选择「软件更新 → 打开更新页」。下载 ZIP 后，回到软件点击「安装更新包」并选择原 ZIP。更新器会校验发布签名和版本，安装后重新打开词间。
- 如果当前版本没有「软件更新」，先从托盘退出旧版，再用下载包里的 `Cijian.exe` 替换旧文件。已保存的练习进度会从 Windows 用户目录读取。

## 从源码构建

在 Windows 上使用 PowerShell 和系统的 64 位 .NET Framework 4.x 编译环境。考研词频表需自行准备，至少包含 51 个不同词条，使用 UTF-8 编码。每行依次写单词和释义，中间用一个 Tab 分隔。

```powershell
.\Build-Release.ps1 -Repository 'isL-dev-lj/cijian' -WordList 'C:\path\GraduateFrequency.tsv'
```

脚本会编译程序、运行自检，并生成 `dist\Cijian-Update.zip`。参数 `-Repository` 决定应用内的 GitHub 更新页地址。提交词库或将其打入公开发行包前，请确认拥有相应的分发权限。

### 维护者发布

1. 更新 `MoyuPractice.cs` 中的程序集版本号。
2. 运行构建脚本并传入 `-PublisherKeyFile`，使用发布者的 DPAPI 加密私钥为 ZIP 签名。公开仓库保存用于验证的公钥。
3. 将原始 ZIP 上传到对应版本的 GitHub Release，发布前验证从上一版安装升级时能读回已有进度。

已有 1.0.3 或更早格式的考研进度，且需要换词表时，先用原词库运行 1.0.4 或更高版本，让软件自动写入词条 ID。直接用不同词表读取旧格式存档时，程序会保留旧存档备份。
