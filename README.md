# 词间 Cijian

词间是一款 Windows 英语练习工具。按快捷键呼出半透明浮窗，看中文拼英文，练完按 `Esc` 收起。词间会根据拼写结果安排下一次复习，也能接收 Reading Desk 的阅读生词。

[GitHub 发布页](https://github.com/isL-dev-lj/cijian/releases) · [快速上手](#快速上手) · [复习规则](#复习规则) · [导入阅读生词](#导入阅读生词) · [从源码构建](#从源码构建)

本文对应 **1.6.1 预览版**。

## 快速上手

1. 下载 Windows 便携 ZIP 或使用已收到的预览包，解压后运行 `Cijian.exe`。
2. 在管理页选择词库和「记忆」模式，点击「开始练习」。可选考研大纲词频、六级词库或六级句子库。
3. 根据释义或译文拼写。卡住时按 `Tab`，剩余拼写会在输入行显示，继续输入时提示自动收起。

| 操作 | 用法 |
| --- | --- |
| 打开或收起浮窗 | 默认 `Ctrl+Shift+O`。被占用时尝试 `Ctrl+Shift+F10`。 |
| 收起浮窗 | 按 `Esc`，或点击浮窗右上角的 ×。 |
| 移动浮窗 | 按住拼写行、词义或空白处拖动。本次运行中，再次呼出会沿用拖动后的位置。 |
| 播放发音 | 点击拼写行。 |
| 打开管理窗口 | 双击系统托盘的词间图标，或在右键菜单选择「管理练习」。 |
| 完全退出 | 在托盘右键菜单选择「退出」。 |

## 练习模式

| 模式 | 适合怎么练 |
| --- | --- |
| 记忆 | 看中文拼英文。拼对后自动评级，由 FSRS 安排下次复习。三个词库均支持。 |
| 词义复习 / 跟打 | 考研词库用「词义复习」补练拼写评为「模糊」或「忘了」的词。六级词库和句子库用「跟打」照着完整拼写输入。 |
| 刷词 | 按词表顺序连续跟打，进度单独保存。 |

拼错时，只重打当前单词，词组和句子里前面拼对的词会保留。管理页可以分别开关自动朗读与练习提示音。

### 词义复习怎么用

考研词在「记忆」中评为「模糊」或「忘了」后，可切换到「词义复习」补练。看到英文后先想中文，按空格或点击核对释义，再按 `1`、`2`、`3` 选择「记得」「模糊」「忘了」。暂无待补练词时，可以回到「记忆」继续练拼写。该词的拼写评级恢复到「记得」后，会移出补练队列。

词义复习时按 `F2` 可以标熟，约 14 天后抽查。误按评分或标熟时，用 `Ctrl+Z` 撤销上一次操作。

## 复习规则

### 拼写自动评级

| 拼写情况 | 评级 |
| --- | --- |
| 未用提示，拼错 0–3 次 | 记得 |
| 未用提示，拼错 4–10 次 | 模糊 |
| 拼错 11 次或以上，或用过 `Tab` 提示 | 忘了 |

评级完成后直接进入下一题。词间会尽量把「忘了」的题隔 3 题安排一次返场。返场单独记账，跨天复习日期由该轮首次评级决定。

### FSRS-6 与组词

拼写复习使用 FSRS-6 的默认参数，目标回忆率为 90%。算法根据每个词条的难度、记忆稳定性和距上次练习的时间，结合本次评级计算下次复习日期。词义补练单独保存评分和排程，拼写日期由实际拼写评级更新。

通常每组安排 40 个词，含返场最多 50 题。词间优先出到期词，积压时减少新词。有空位时先安排阅读生词，再按词频补充考研词。组末显示完成词数和返场次数，点「继续」或按 `Enter` 开下一组。

## 导入阅读生词

- **手动导入**。在 Reading Desk 的阅读工具栏选「导出到词间」，再在词间管理页点「导入阅读生词」，选下载的 JSON 文件。
- **自动接收**。把 `Cijian.ReadingInbox.txt` 放在 `Cijian.exe` 旁边，在文件里填定时任务交付目录的绝对路径。任务把 JSON 保存为 `cijian-*.json`。词间启动时会检查该目录，浮窗收起期间每 30 秒再检查一次。成功导入后，同目录会生成后缀为 `.imported` 的回执。

导入使用词头和释义。已有词提高拼写队列优先级，新词加入考研练习队列。管理页显示最近一次自动接收的时间和结果。

```json
{
  "Format": "cijian-reading-v1",
  "Words": [
    { "Word": "account for", "Meaning": "解释；说明……的原因。" }
  ]
}
```

## 进度、发音与升级

- 练习进度、FSRS 排程、导入词条和设置保存在 `%LOCALAPPDATA%\MoyuPractice\progress.txt`。
- 英语单词和短语优先使用与 Reading Desk 同源的有道在线发音。在线播放会向它请求当前英文词条。网络不可用时回退到 Windows 语音，句子使用 Windows 语音。
- **便携预览版升级**。从系统托盘退出旧版，解压并运行新包里的 `Cijian.exe`。如果已配置自动收词，把现用的 `Cijian.ReadingInbox.txt` 一起放在新版程序旁边。已有进度会从 Windows 用户目录读取。
- **应用内更新**。从「软件更新 → 打开更新页」下载带发布签名的 ZIP，再点「安装更新包」选择该文件。更新器会校验签名和版本，安装后重新打开词间。

## 从源码构建

在 Windows 上使用 PowerShell 和系统的 64 位 .NET Framework 4.x 编译环境。考研词频表需自行准备，至少包含 51 个不同词条，使用 UTF-8 编码。每行依次写单词和释义，中间用一个 Tab 分隔。

```powershell
.\Build-Release.ps1 -Repository 'isL-dev-lj/cijian' -WordList 'C:\path\GraduateFrequency.tsv'
```

脚本会编译程序、运行自检，并生成 `dist\Cijian-Update.zip`。参数 `-Repository` 决定应用内的 GitHub 更新页地址。可通过 `-FrequencyList` 提供 UTF-8 通用词频表，每行一个词，按频率从高到低排列。提交词库或将其打入公开发行包前，请确认拥有相应的分发权限。

### 维护者发布

Windows 安装包使用 Windows SDK 的 MSI 工具构建。安装到当前用户的 `%LOCALAPPDATA%\Cijian`，可从开始菜单打开，也可以在 Windows 的「已安装的应用」中卸载。学习进度仍保存在 `%LOCALAPPDATA%\MoyuPractice`，卸载程序会保留这个目录。

```powershell
.\Build-Installer.ps1 -WordList 'C:\path\GraduateFrequency.tsv' -FrequencyList 'C:\path\GraduateRanks.txt'
```

安装包输出为 `dist\Cijian-<版本>-Setup.msi`。便携版用户安装前先从系统托盘退出旧版。Windows 代码签名和下面的 ZIP 发布签名分别用于不同的验证流程。

发布 Windows 签名版时，在签名用户的 `CurrentUser\My` 证书库中配置公开受信任的代码签名证书，确认私钥可用，然后按证书服务商提供的 RFC 3161 时间戳地址构建。

```powershell
.\Build-Installer.ps1 -WordList $wordList -FrequencyList $frequencyList -SigningThumbprint $thumbprint -TimestampUrl $timestampUrl
```

脚本先签名 `Cijian.exe`，再生成并签名 MSI。两处验签通过后输出 MSI 和包含已签名 EXE 的便携 ZIP。

使用 ZIP 更新渠道时，按以下步骤生成应用内可以安装的更新包。

1. 更新 `MoyuPractice.cs` 中的程序集版本号。
2. 以保护原私钥的 Windows 用户身份运行构建脚本并传入 `-PublisherKeyFile`，使用发布者的 DPAPI 加密私钥签名。公开仓库保存用于验证的公钥。可以同时传入 `-SigningThumbprint` 和 `-TimestampUrl`，让更新包里的 EXE 也具备 Windows 代码签名。
3. 将原始 ZIP 上传到对应版本的 GitHub Release，发布前验证从上一版安装升级时能读回已有进度。

已有 1.0.3 或更早格式的考研进度，且需要换词表时，先用原词库运行 1.0.4 或更高版本，让软件自动写入词条 ID。直接用不同词表读取旧格式存档时，程序会保留旧存档备份。
